# InternNova Week 3 – Object-Oriented Programming



The assignment covers classes and objects, constructors, `this` and `static`, inheritance, polymorphism, encapsulation, and abstraction.



---

## 📚 Tasks Covered

### Task 1 – Classes & Objects
Created a Student Management program using:
- Classes
- Objects
- Instance variables
- Object methods

The program creates multiple Student objects and displays their details.

### Task 2 – Constructors
Created an Employee Information program demonstrating:
- Default constructor
- Parameterized constructor
- Constructor initialization

### Task 3 – `this` & `static`
Created a Bank Account program demonstrating:
- `this` keyword
- Instance variables
- Static variables
- Object creation

The program also tracks the total number of bank accounts created.

### Task 4 – Inheritance
Created an Employee Management program demonstrating:
- Parent class
- Child classes
- `extends`
- `super`
- Code reusability

The program contains `Developer` and `Manager` classes derived from the `Employee` class.

### Task 5 – Polymorphism
Demonstrated both:
- Method Overloading
- Method Overriding

The program includes overloaded `calculate()` methods and overridden `start()` methods for different vehicles.

### Task 6 – Encapsulation & Abstraction
Created a Banking System demonstrating:
- Private variables
- Getters and setters
- Abstract classes
- Abstract methods
- Method implementation in child classes
